# Search Engines
A search engine is a software program that helps people find information on the internet when they type in words or questions.<br>

<details><summary>Popular Search Engines</summary> 

- General:
    * Google
    * Bing
    * Yahoo
    * DuckDuckGo(privacy-focused)
    * Baidu(China)
    * Yandex

- AI-powered
    * Perplexity
    * You.com
    * Brave Search
    * Andi
    * Komodo AI
</details>

<details><summary>Search Engine Types</summary>

* Web search engines – Google, Bing
* Image search engines – Google Images
* Video search engines – YouTube
* Academic search engines – Google Scholar
* Enterprise search engines – Search within company data<br>
</details>
